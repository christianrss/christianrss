# Christian Rafael de Souza Silva

**Software Engineer · ML Systems & AI Infrastructure · Systems Programming**

I build software and computing systems from first principles. My work spans operating-system internals, compilers and virtual machines, language-model training and inference, accelerated computing, and software platforms.

I am particularly interested in understanding the complete execution path of a system—from algorithms and memory to hardware, distributed infrastructure, and the applications built on top.

## Selected projects

### [ChrisOS — Operating system and systems research](https://github.com/christianrss/ChrisOS)
An experimental x86-64 operating system with a custom kernel, memory management, storage and network drivers, a desktop environment, and graphics experiments. The wider project includes the ChrisC language, CLVM runtime, native toolchain, and ChrisVM/ChrisCPU emulation work. Developed as an ongoing, documented systems-engineering project—not a production-ready OS.

### [Chris-GPT-2 — Language model pretrained from scratch](https://github.com/christianrss/chris-gpt-2)
Implemented and pretrained a 124M-parameter GPT-2-style language model from randomly initialized weights on approximately **10 billion FineWeb-Edu tokens**, using **4 NVIDIA A100 GPUs**. The project covers distributed training, evaluation, checkpointing, model export, and inference. [Model and weights](https://huggingface.co/christianrss/chris-gpt-2-124m).

### [Chris Llama — Low-level LLM inference runtime](https://github.com/christianrss/chris-llama)
An experimental inference runtime for GPT-style models, with GGUF loading, tokenization, KV caching, sampling, quantized-weight support, and CPU and AdaptiveCpp/SYCL execution paths.

### [Chris Torch — Deep learning framework](https://github.com/christianrss/chris-torch)
A learning-focused tensor and automatic-differentiation framework with dynamic computation graphs, neural-network abstractions, gradient checking, and native C++/SYCL compute integration.

### [Engineering Manual — Technical knowledge base](https://github.com/christianrss/manual)
A bilingual engineering reference covering computer science, software engineering, algorithms, data structures, system design, and related foundations. Built with a static publishing pipeline, search, and structured learning paths. [Read online](https://manual.christiansoftware.org/).

### [Marginal Thinking — Research and publishing platform](https://github.com/logicvisionai/marginalthinking)
An independent research platform focused on macroeconomics, markets, political economy, and geopolitics, supported by a reproducible publishing pipeline and machine-readable research interfaces. [Visit the site](https://marginalthinking.org/).
